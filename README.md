# VR 운전면허 마스터 🚗🥽

**VR로 운전면허 장내기능시험과 도로주행 시험을 연습하는 시뮬레이터**입니다.
Meta Quest 같은 VR 헤드셋이나 PC 화면에서 실행되고, **레이싱 페달이나 발에 묶은 VR 컨트롤러로 실제처럼 발로 운전**할 수 있습니다.
차량은 2026년형 전기 크로스오버(가상의 최신형 차량)입니다.

> 설치할 프로그램이 없습니다. 웹 브라우저에서 바로 실행됩니다 (Three.js + WebXR).

## 🛣️ 경부고속도로 VR 드라이브 (서울 ↔ 부산) — `trip.html`

**승용차를 타고 서울에서 부산(또는 부산에서 서울)까지 경부고속도로 422 km를 실제 속도로 4시간 30분 동안 달리는 VR 드라이브**입니다.
고속버스가 다니는 그 길을 그대로 따라가고, 운전은 자율주행이 하니 창밖 구경만 하면 됩니다.

### 시작하기

1. GitHub Pages를 켠 뒤(위 "실행 방법" 참고) **Quest 브라우저**에서 `https://<아이디>.github.io/Drive/trip.html` 을 엽니다.
   (운전면허 연습 첫 화면 아래의 **🛣️ 서울↔부산 경부고속도로 VR 드라이브** 링크로도 갈 수 있어요.)
2. 방향(서울→부산 / 부산→서울), 좌석(조수석·운전석·뒷좌석), 출발 시각, 화질을 고르고 **[VR로 시작]**.
   PC에서는 **[PC 화면으로 시작]** 으로 같은 여행을 모니터로 볼 수 있어요.
3. 의자에 앉아서 보세요. 위치가 어긋나면 **Y 버튼**(또는 Oculus 버튼 길게)으로 정면을 맞춥니다.
4. 진행 위치는 5초마다 저장됩니다. 다음에 **[이어서 보기]** 로 계속할 수 있어요 (VR은 "VR도 이어서 보기로 시작" 체크).

### 화질과 성능

- **보통**(기본): Quest 3에 맞춤. 가까운 지형 약 1 m급 사진(고화질은 0.5 m급), 나무 300 m 안.
- **가볍게**: Quest 2나 끊길 때. 나무와 디지털 미러를 끄고 지형 단계를 낮춤.
- **고화질**: PC VR(Quest Link/Air Link + PC Chrome/Edge)이나 고성능 PC.
- 인터넷으로 지형·위성사진을 계속 받으므로 와이파이가 빠를수록 좋아요. 연결이 안 되면 사진 대신 색으로 그립니다.

### 위성사진 바꾸기 (VWorld 항공사진)

국토교통부 [VWorld](https://www.vworld.kr)에서 무료 인증키(2D 지도 API, 서비스 URL에 GitHub Pages 주소 등록)를 받아
시작 화면의 **위성사진 → VWorld 항공사진**을 고르고 키를 넣으면 한국 지역이 더 선명해집니다.
주소 뒤에 `?tiles=https://…/{z}/{x}/{y}.jpg` 를 붙이면 다른 타일 서버도 쓸 수 있어요.

### 데이터 다시 만들기

```bash
pip install pyarrow shapely scipy numpy pillow requests
python3 tools/build_trip_data.py          # 10~20분 (Overture Maps에서 필요한 부분만 받음)
python3 tools/build_trip_data.py --buildings-only   # 건물만 다시
```

결과는 `data/trip/`(약 5 MB)에 저장됩니다: 차로 중심선·높이·교량/터널·차로 수·제한속도(`route_SB.bin`, `route_NB.bin`),
램프(`ramps.bin`), 출구 안내·휴게소·지명·고가(`meta.json`), 건물(`bld/*.bin`).

### 알아 두세요

- 지형 고도는 30 m 해상도(SRTM)라서 작은 언덕·절토면은 실제와 조금 다를 수 있고, 도로 높이는 이를 매끄럽게 다듬은 값입니다.
- 터널·교량·출구 위치는 실제지만, 터널 이름·교각 모양·방음벽 위치·건물 높이 일부는 추정값입니다.
- 휴게소에 실제로 들어가 쉬지는 않아요(안내 표지만). 피곤하면 멈춤을 누르고 쉬었다가 이어서 보세요.
- 도로·건물·지명 © OpenStreetMap contributors, Overture Maps Foundation (ODbL) · 지형 AWS Terrain Tiles(Mapzen, SRTM 등) ·
  위성사진 Esri, Maxar, Earthstar Geographics / 국토교통부 VWorld. 개인 감상용으로 쓰고, 다른 용도라면 각 서비스 약관을 확인하세요.

## 실행 방법

### 1) 가장 쉬운 방법: GitHub Pages로 바로 열기

1. GitHub 저장소 → **Settings → Pages**
2. **Source: Deploy from a branch** → 이 코드가 있는 브랜치(예: `main`) / `(root)` 선택 → Save
3. 1~2분 뒤 `https://<아이디>.github.io/Drive/` 주소가 생깁니다.
4. 그 주소를 **Quest 브라우저**나 PC 브라우저에서 엽니다.

> VR(WebXR)은 보안상 **https 주소**에서만 동작합니다. GitHub Pages는 자동으로 https입니다.

### 2) 내 PC에서 실행

```bash
# 이 폴더에서
npx serve .          # 또는: python3 -m http.server 8000
```

브라우저에서 `http://localhost:3000` (python은 `:8000`)을 엽니다. `index.html`을 더블클릭하면 모듈 로딩 제한 때문에 동작하지 않으니 꼭 서버로 여세요.

## 🏙️ 도로주행 시험

메뉴에서 **[도로주행 시험]** 또는 **[도로주행 연습]**을 고르세요. 연습에서는 실수해도 끝나지 않고 무엇이 틀렸는지 알려 줍니다.

**경로:** 정차 구역에서 출발(왼쪽 깜빡이) → 중앙대로 직진 → 1차로로 바꿔 **좌회전** → 시청로 → **일시정지** 후 좌회전 → 북부로 → 좌회전 → 학교길(**어린이보호구역 30km/h**, 신호 없는 횡단보도 앞 **일시정지**) → **우회전** → 중앙대로 → 오른쪽 깜빡이 켜고 파란 **"도착"** 구역에 정차 → P단

- 화면 위쪽과 계기판에 다음 안내(예: `↰ 좌회전 120m`)와 **제한속도 표지**가 나오고, 센터 화면에 **경로 지도**가 보여요.
- 음성으로 "150미터 앞 교차로에서 좌회전입니다. 1차로로 미리 진로를 변경하세요" 같이 안내해요.
- 다른 차들은 신호를 지키고 앞차와 거리를 두며 달려요. 부딪히면 **교통사고로 실격**이에요.
- 안내와 다른 길로 가면 감점 후 원래 경로로 돌아가요.

| 항목 | 감점 |
| --- | --- |
| 출발 시 방향지시등 미작동 / 정차 시 오른쪽 방향지시등 미작동 | -5 |
| 차로 변경 시 방향지시등 미작동 / 교차로 앞 실선 구간에서 차로 변경 | -7 |
| 좌회전은 1차로, 우회전은 맨 오른쪽 차로가 아님 | -7 |
| 회전 전 방향지시등 미작동 / 정지선 침범 / 급제동·급출발 / 안전거리 미확보 / 차로 걸침·가장자리 침범 / 경로 위반 | -5 |
| 일시정지 위반 / 어린이보호구역 횡단보도 일시정지 위반 / 빨간불 우회전 전 일시정지 위반 | -10 |

**실격:** 신호위반, 중앙선 침범, 제한속도 10km/h 초과, 어린이보호구역 30km/h 초과, 보행자 보호 위반, 교통사고(충돌), 보도·연석 침범, 안전띠 미착용, 70점 미만.

## 핸들 조작감 설정

깊게 꺾을 때 불편하면 **[설정]**에서 바꿀 수 있어요 (VR에서는 센터 화면 [설정 · 발 보정]).

- **핸들 감도:** 빠름(끝까지 3/4바퀴) / **보통(1바퀴, 기본)** / 실제 차(1.25바퀴)
- **핸들 자동 복귀:** 주행 중 손을 떼면 천천히 가운데로 돌아와요. 손을 바꿔 잡는 잠깐(0.7초) 사이에는 돌아가지 않아서 깊게 꺾을 때 튕기지 않아요. 끌 수도 있어요.
- 키보드 ←/→는 처음엔 천천히(미세 조정), 계속 누르면 빨라져요(깊게 꺾기). 반대로 꺾여 있으면 빠르게 가운데로 돌아와요.
- 화면 조작 핸들은 손가락으로 조금만 돌려도 1.5배로 꺾여요.

## 시동이 안 걸려요? (브레이크 밟는 법)

실제 차처럼 **브레이크를 밟은 채 START**를 눌러야 시동이 걸립니다. 브레이크는 이렇게 밟아요.

| 쓰는 장치 | 브레이크 | 시동 순서 |
| --- | --- | --- |
| 키보드 | `↓` 키 | `B`(안전벨트) → `↓`를 누른 채 `Enter` → `D` → `↑` |
| VR 컨트롤러 | 왼손 트리거 | [안전벨트] 버튼을 손끝으로 → 왼손 트리거를 당긴 채 오른손 스틱 누르기(또는 START 버튼) → 오른손 스틱 뒤로(D) → 오른손 트리거 |
| 게임패드(엑스박스·PS) | LT | 십자키 ←(안전벨트) → LT를 당긴 채 A → 십자키 ↓(D) → RT |
| 화면 버튼 | [브레이크] 버튼 | [벨트] → [START] → [D] → [가속] 길게 누르기 |

**간편 조작**(기본으로 켜짐): 브레이크를 안 밟고 START나 변속을 누르면 자동으로 브레이크를 밟아 줍니다. 실제처럼 엄격하게 연습하려면 설정에서 끄세요.
연습 모드에서는 안전벨트를 안 매도 출발할 수 있지만, 시험 모드에서는 안전벨트를 매야 주차 브레이크가 풀립니다 (안 매고 출발하면 실격).

## 화면 조작 버튼 (휴대폰·태블릿·마우스)

키보드나 VR 컨트롤러가 없어도 화면의 버튼으로 운전할 수 있어요. 터치 화면에서는 자동으로 나타나고, PC에서는 오른쪽 아래 **[화면 버튼]**으로 켜고 끕니다.

- 왼쪽 아래 **핸들**: 손가락(마우스)으로 원을 따라 돌리기
- 오른쪽 아래 **[브레이크] [가속]**: 누르고 있는 동안 밟힘 (길게 누를수록 깊게)
- 가운데 버튼: START, 벨트, EPB, 비상등, P·R·N·D, 방향지시등, 전조등, 상향등, 와이퍼, 시점, 메뉴

## VR 헤드셋에서 하기 (Meta Quest 기준)

1. **의자에 앉아서** Quest 브라우저로 페이지를 열고 **[VR로 시작]**
2. 차 안 운전석에 앉은 시점으로 들어갑니다. 위치가 어긋나면 센터 화면의 **[시점 재설정]** (또는 Oculus 버튼 길게 누르기)
3. 센터 터치스크린을 **손끝으로 눌러서** `장내기능시험 시작` / `연습 주행`을 고릅니다. P단일 때는 화면을 가리키고 트리거를 당겨도 됩니다.

| VR 컨트롤러 | 기능 |
| --- | --- |
| 오른손 트리거 | 가속 페달 |
| 왼손 트리거 | 브레이크 |
| 그립 버튼 | 핸들 테두리를 잡고 실제처럼 돌리기 (양손 가능) |
| 손끝으로 누르기 | 기어(P·R·N·D), EPB, START, 비상등, 안전벨트, 전조등, 와이퍼, 화면 |
| 오른손 A / B | 오른쪽 방향지시등 / 와이퍼 |
| 왼손 X / Y | 왼쪽 방향지시등 / 비상등 |
| 오른손 스틱 앞/뒤 | 기어를 P 쪽 / D 쪽으로 (D→N→R→P) |
| 왼손 스틱 앞/뒤 | 전조등 밝게 / 어둡게 (좌우: 핸들을 안 잡았을 때 조향) |
| 오른손 스틱 누르기 | 시동 |
| 왼손 스틱 누르기 | 주차 브레이크 |

## ✋ 손으로 운전하기 (Meta Quest 핸드 트래킹)

컨트롤러 없이 **맨손으로** 운전할 수 있어요. 컨트롤러를 내려놓으면 Quest가 자동으로 손을 인식합니다 (Quest 설정 → 움직임 추적 → **손 추적** 켜기). 손이 인식되면 화면과 음성으로 사용법을 알려 줘요.

| 동작 | 손으로 |
| --- | --- |
| 핸들 | 핸들 테두리에 손을 대고 **주먹을 쥐면** 잡혀요. 쥔 채로 돌리고, 손을 펴면 놓아요 (한 손으로도 OK) |
| 가속 페달 | 핸들을 잡지 않은 **오른손으로 엄지·검지 집기** (집는 만큼 깊게) |
| 브레이크 | 핸들을 잡지 않은 **왼손으로 엄지·검지 집기** |
| 버튼 | **검지 끝으로 누르기**: 기어 P·R·N·D, START, 안전벨트, EPB, 비상등, 전조등, 와이퍼, 센터 화면 |
| 방향지시등 | 핸들 가운데 양옆의 **◀ ▶ 버튼**을 검지로 |

팁: 오른손으로 가속할 땐 왼손으로 핸들을 잡고, 브레이크를 밟을 땐 오른손으로 핸들을 잡으세요. 손을 편하게 두었을 때는 페달이 밟히지 않도록 확실히 집어야 반응해요.

## 🦶 발로 운전하는 3가지 방법

### ① 레이싱 페달 / 레이싱 휠 — 가장 실감 나요
로지텍(G29·G923 등), 스러스트마스터, 파나텍 같은 USB 페달·휠을 연결하고 **[발 페달 · 핸들 설정] → [페달·핸들 보정 시작]**.
화면 안내대로 "페달에서 발 떼기 → 가속 끝까지 → 브레이크 끝까지 → 핸들 오른쪽 끝까지"를 측정하면 어떤 장치든 맞춰집니다. 방향지시등·기어·비상등·EPB용 버튼도 지정할 수 있어요.

- **VR + 페달을 함께 쓰려면 PC VR**이 필요합니다: Quest Link / Air Link 또는 SteamVR로 연결한 뒤 **PC의 Chrome/Edge**에서 페이지를 열고 [VR로 시작].
- Quest 단독 브라우저는 USB 레이싱 페달을 인식하지 못할 수 있습니다.
- 엑스박스 등 표준 게임패드는 보정 없이 RT=가속, LT=브레이크, 왼쪽 스틱=핸들로 바로 동작합니다.

### ② VR 컨트롤러를 발에 묶기 — 추가 장비 없이!
1. 컨트롤러 하나(보통 오른쪽)를 **오른발 등(신발 끈 위)에 벨크로·고무줄로 단단히** 묶습니다.
2. VR 안에서 센터 화면 **[설정 · 발 보정] → [발 컨트롤러 모드]**를 켜고 **[발 보정 시작]**.
3. 안내대로 4번 측정: 가속 위치에 발 올리기 → 가속 끝까지 → 발끝을 왼쪽(브레이크)으로 옮기기 → 브레이크 끝까지
4. 이제 실제 운전처럼 **뒤꿈치를 바닥에 대고 축으로 삼아** 발끝을 왼쪽으로 돌리면 브레이크, 오른쪽이면 가속이고, **발끝을 누르는 만큼** 밟힙니다.

발의 기울기는 컨트롤러 내부 센서(IMU)로 읽기 때문에 발이 헤드셋 카메라에 안 보여도 동작합니다. 다른 손 컨트롤러로 핸들을 잡고, 나머지 버튼은 손끝으로 누르면 됩니다.

### ③ USB 발판 스위치
키보드 키를 보내는 발판 스위치(풋 스위치)를 ↑(가속), ↓(브레이크) 키로 설정하면 바로 쓸 수 있습니다. 세기 조절은 안 되고 켜기/끄기만 됩니다.

## 연습 팁

- **경사로:** 앞범퍼가 노란 정지구간 안에 들어오면 정지. 출발할 때 브레이크에서 가속 페달로 발을 옮기는 사이에 차가 뒤로 밀립니다. 이 차는 실제 시험처럼 **언덕 밀림 방지가 꺼져 있어요** (설정에서 켤 수 있음).
- **직각주차:** 주차칸을 지나쳐 정지 → R → 핸들을 오른쪽으로 감고 천천히 후진 → 완전히 들어가면 정지 + EPB. 연습 모드의 **주행 궤적 가이드**(노란 선)와 **위에서 보기(V)**가 큰 도움이 됩니다.
- **돌발:** 경고음이 울리면 바로 브레이크 → 비상등 → 출발 안내가 나오면 비상등을 끄고 출발.
